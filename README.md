### Proyectos

**[LegalManager — Sistema de Gestión Jurídica Integral](https://github.com/francocus/gestion-legal-estudio)**
Proyecto personal. Plataforma full-stack para la administración integral de estudios jurídicos, adaptable a distintas jurisdicciones (Argentina y Paraguay). Centraliza gestión de clientes, seguimiento de expedientes judiciales y extrajudiciales, biblioteca jurídica vinculada a cada causa, control financiero y agenda con alertas de vencimientos. Control de acceso basado en roles (administrador, abogado, cliente) con autenticación mediante Auth.js. Integra IA (Google Gemini) para análisis comparativo de normativa y validación automática de fuentes legales oficiales por país.
Stack: Next.js 16, React, TypeScript, Prisma, PostgreSQL, Tailwind CSS, Shadcn/ui.

**[RentIA — Asistente con IA para alquilar en Rosario](https://github.com/francocus/RentIA)**
Desarrollado en la hackathon Shippear. Permite a inquilinos subir su contrato de alquiler (PDF o imagen) y recibir una explicación en lenguaje simple de las cláusulas de riesgo y cambios normativos recientes, comparar precios de alquiler por zona y simular ajustes futuros según el índice de actualización. Ofrece a inmobiliarias análisis de postulantes asistido por IA.
Stack: Next.js, React, TypeScript, Vercel AI SDK (Google Gemini), MCP, Drizzle ORM sobre PostgreSQL, better-auth, Stripe.
